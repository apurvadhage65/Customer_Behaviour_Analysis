# Customer Shopping Behavior – Data Analysis Project

## 📌 Overview
This project analyzes customer shopping behavior to identify sales trends, high-value customers, popular product categories, and purchasing patterns.  
It demonstrates an end-to-end data analytics workflow using Python, PostgreSQL, and Power BI.

---

## 📂 Dataset
**Customer Shopping Behaviour Dataset**  
Contains customer transactions including purchase amount, category, payment method, location, and date.

---

## 🛠 Tools & Technologies
- Python (Pandas, Matplotlib)
- PostgreSQL (pgAdmin)
- SQL
- Power BI
- Jupyter Notebook

---

## ⚙ Project Steps
1. Loaded the dataset using Python (Pandas)
2. Performed Exploratory Data Analysis (EDA)
3. Cleaned and prepared data for analysis
4. Loaded data into PostgreSQL database
5. Wrote SQL queries to answer business questions
6. Built an interactive Power BI dashboard

---

## 📊 Dashboard
The Power BI dashboard includes:
- Total sales and revenue trends  
- Top customers and best-selling categories  
- Payment method distribution  
- Monthly sales performance  
- Customer spending patterns  

*(Dashboard screenshots are available in the screenshots folder.)*

---

## 📈 Results & Insights
- Identified top-spending customers  
- Found highest revenue-generating product categories  
- Discovered monthly sales trends and peak shopping periods  
- Analyzed preferred payment methods  

---

## ▶ How to Run the Project
1. Clone this repository  
2. Open the Jupyter Notebook and run all cells to load and clean data  
3. Load the cleaned data into PostgreSQL  
4. Execute SQL queries from the `sql_queries` folder  
5. Open the Power BI file to view the dashboard
